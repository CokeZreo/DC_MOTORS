# DC_MOTORS —— 基于 STM32 的直流电机 H 桥调速系统

用 STM32F103C8T6 驱动一个自制的 H 桥（4 个 N-MOS + 2 片半桥驱动），实现
**正反转 + 20 kHz PWM 调速 + 电压电流实时检测 + OLED 显示**。

> 本项目仅供学习交流，**禁止商业使用**，详见 [LICENSE](LICENSE)。

## 功能

- **PWM 调速**：20 kHz，占空比 20%~90%，按键步进 10%
- **正反转**：单键切换，换向自动降速到 20% 软启动
- **换向保护**：先全关 → 断电 10 ms → 切方向 → 低速起步
- **电压检测**：0~13 V
- **电流检测**：0~2 A，显示分辨率 0.01 mA（软件滤波后）
- **OLED 显示**：电压 / 电流 / PWM 占空比 / 转向，四行实时刷新（50 ms）
- **状态指示**：两颗 LED 分别指示正转 / 反转

## 硬件

| 器件 | 型号 | 说明 |
|---|---|---|
| 主控 | STM32F103C8T6 | LQFP48，72 MHz，64 KB Flash / 20 KB RAM |
| 半桥驱动 | XJNG2103 × 2 | IR2103 兼容，自举式高边驱动 |
| 功率 MOS | TX20N03 × 4 | 30 V / 20 A N 沟道 |
| 电流采样 | 10 mΩ 分流电阻 | 低边采样 |
| 电流放大 | LMV321 + 20 倍同相放大 | 1.2 V 偏置，输出 = 20×Vsense + 1.2 V |
| 显示 | 0.96" OLED (SSD1306) | 128×64，软件 I2C |

### 引脚分配

| 引脚 | 功能 | 说明 |
|---|---|---|
| PB1 | TIM3_CH4 | Q1 上管 A，**正转 PWM** |
| PB0 | GPIO 输出 | Q2 下管 A（低电平导通） |
| PB11 | TIM2_CH4（重映射） | Q3 上管 B，**反转 PWM** |
| PB10 | GPIO 输出 | Q4 下管 B（低电平导通） |
| PA5 | ADC1_IN5 | 电压检测（4:1 分压） |
| PA6 | ADC2_IN6 | 电流检测（运放输出） |
| PB14 / PB15 | GPIO 输出 | 方向指示灯（低电平点亮） |

> TIM2 使用了**部分重映射**，CH3 / CH4 映射到 PB10 / PB11。

### 驱动真值表

| 状态 | Q1 (PB1) | Q4 (PB10) | Q3 (PB11) | Q2 (PB0) |
|---|---|---|---|---|
| 停止 | 0 | 关 (1) | 0 | 关 (1) |
| 正转 | PWM | 开 (0) | 0 | 关 (1) |
| 反转 | 0 | 关 (1) | PWM | 开 (0) |

## 软件设计要点

### 1. 调速与输出分离

按键只修改 `Duty` 变量，循环末尾统一把 `Duty` 换算成 CCR 写入**当前正在输出**的通道：

```c
if (Dir == 1)      __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_4, PWM_PERIOD * Duty / 100);
else if (Dir == 2) __HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_4, PWM_PERIOD * Duty / 100);
```

这样无论方向怎么切换，调速永远作用于「正在跑的那一路」。

### 2. 换向保护

```c
全部关断 → HAL_Delay(10) → 切换方向 → Duty = DUTY_MIN → 按新方向启动
```

- 10 ms 让电机电感电流衰减完（τ = L/R，通常 < 1 ms）；
- 强制 20% 起步，避免高速反接产生的巨大冲击电流。

### 3. PWM 启动顺序

```c
__HAL_TIM_SET_COMPARE(...);   /* 先写占空比 */
HAL_TIM_PWM_Start(...);       /* 再开输出 */
```

保证启动第一拍就是正确占空比，不会用到寄存器里的旧值。

### 4. 电流检测的标定

理论传递函数：

```
Vout = 20 × I × 10mΩ + 1.2V = 0.2 × I(A) + 1.2V
```

实际存在器件误差（VREF 公差、电阻容差、运放失调），因此使用**实测值标定**：

```c
#define ADC_VREF_MV   3280UL     /* 实测 VDDA */
#define CUR_V0_MV     1220.0f    /* 零电流时软件算出的零点 */
#define CUR_K         5.00f      /* 每 mV 对应 5 mA */
```

### 5. 显示处理

| 处理 | 作用 |
|---|---|
| 20 次采样取平均 | 降低 ADC 噪声 |
| 0.01 mA 为单位 | 保留两位小数 |
| 一阶低通滤波 | 显示平滑，末位不跳 |
| 5 mA 死区 | 零电流时稳定显示 0 |

## 编译与烧录

1. 安装 **Keil MDK 5**（ARM Compiler V5），可选安装 **STM32CubeMX** 用于修改外设配置；
2. 打开 `MDK-ARM/DC_MOTORS.uvprojx`；
3. `Options for Target → Target → 勾选 Use MicroLIB`（`sprintf` 需要）；
4. `F7` 编译，`F8` 用 ST-Link 下载。

## 设计中的几个坑

| 问题 | 现象 | 解决 |
|---|---|---|
| 按键调速只在换向时生效 | 屏幕变了但电机不变 | 每轮循环都写 CCR，而不是只在启动时写 |
| 正转能调速、反转不能 | 一个方向调速失灵 | 按键分支写死了定时器，改为按 `Dir` 动态选择通道 |
| 电流零点偏 28 mV | 零电流显示 140 mA | 用实测值替代理论值，并加死区 |
| 100% 占空比掉驱动 | 上管发烫 | 限制最大 90%，给自举电容留充电时间 |
| OLED 刷新闪烁 | 屏幕一亮一暗 | `OLED_Clear()` 只在初始化调用一次 |

## 已知问题 / 后续计划

- [ ] 电流增益未做两点标定，绝对误差约 1%~2%
- [ ] RC snubber（2.2 nF + 330 Ω）预留未焊，满载时需实测漏极尖峰
- [ ] 目前为开环调速，后续可加编码器做闭环
- [ ] OLED 刷新占用约 20 ms（软件 I2C），可换硬件 I2C 或 SPI 提速
